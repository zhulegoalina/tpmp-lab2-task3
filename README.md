# tpmp-lab2-task3

## Overview
Программа для работы со структурой CONTACT по варианту 37.
- Структура CONTACT содержит поля: Name (фамилия и инициалы), TELE (номер телефона), DATE (дата рождения)
- Ввод данных в массив BLOCKNOTE из 10 структур
- Упорядочивание записей по возрастанию даты рождения
- Поиск человека по номеру телефона

Структура проекта согласно модели КИС:

- include/ - заголовочные файлы
- bin/ - исполняемые файлы
- obj/ - объектные файлы
